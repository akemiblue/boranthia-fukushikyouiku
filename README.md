# ボランティアカフェ

大郷町社会福祉協議会　ボランティアセンター事業の新規プログラム。

平時から住民どうしが顔見知りになる場をつくり、孤立・孤独のない地域をめざします。
講座（知る）と活動（やってみる）のあいだにある「また会う」場を、この事業で埋めます。

## ファイル

- `volunteer-cafe-roadmap.html` — 構想と行程（ロードマップ）第1版。ブラウザで開けます。1ファイル完結。
- `volunteer-cafe-youkou.html` — 第1回の開催要項（案）。A4縦1枚で印刷できます。
- `volunteer-cafe-chirashi.html` — 第1回の住民配布用チラシ（案）。A4縦1枚。回覧・町広報・SNSの原稿も入っています。
- `ボランティアカフェ_開催準備リスト_20261215.xlsx` — 準備リストのエクセル版（6シート・103項目・グラフつき）。
- `volunteer-cafe-checklist.html` — 第1回の開催準備リスト（開催日からの逆算・全96項目）。チェックを入れると、その端末に保存されます。

## 収録している内容

- ビジョン（住民に示すことば）と、共有したい3つの考え方
- 「つながりの環」の図 — いま欠けている環がどこかを示したもの
- 4年間のロードマップ（準備期／第1期 定着／第2期 展開／第3期 住民の手に）
  - 各期の「この期の問い」「やること」「到達のめやす」
- 当日90分の型（受付から、ふりかえりまで）
- 評価のしかた — 出会い・関係・動きの3層と、いちばん大事なひとつの数字
- 体制と役割、予算のめやす
- つまずきそうなところと、打ち手（6項目）
- これからの3か月でやること
- 住民向けの案内文（チラシ・回覧・町広報の原稿としてそのまま使えます）

## 開催準備リスト（`volunteer-cafe-checklist.html`）

第1回に向けて、開催日から逆算した「やらなければいけないこと」を10のまとまりに分けたものです。
盆栽ボランティアと災害ボランティアセンター運営体験を、当日のプログラムに入れる想定で組んでいます。

- 逆算スケジュール（8週前 → 当日 → 事後）
- A 会場をおさえる ／ B 事務の手続き
- C チラシと広報 ／ D 参加記念品
- E カフェで使う備品（そのまま当日の積み込みリストになります）／ F 会場に貼る表示物
- G 盆栽ボランティアの準備 ／ H 災ボラ体験の資料
- I 当日の運営 ／ J 終わったあと

チェックの状態はブラウザに保存されるので、開き直しても消えません（端末ごとの保存です。
複数人で共有する場合は、印刷して1枚を回してください）。A4縦で印刷できます。

**盆栽ボランティアの想定** — 「町内の方に教わりながら、小さな鉢をひとつ仕立てて持ち帰る」体験と、
その先に「お宅の庭木や鉢の手入れを手伝う活動」を立ち上げる、という想定で書いています。
想定がちがう場合は、Gの項目を差し替えてください。

## チラシ（`volunteer-cafe-chirashi.html`）

第1回に配る、住民向けのチラシです。開催要項の内容と合わせてあります。A4縦1枚で刷れます。

- おもて面 — 「お茶を飲みに来るだけで、かまいません」から、とき・ところ、当日やること3つ、問い合わせまで
- 画面の下半分（印刷されません）に、同じ内容を字数べつに書き分けた原稿が4本あります
  - ① 町広報 用（約210字）／ ② 行政区の回覧 用（約150字）／ ③ ホームページ・SNS 用（約120字）
  - ④ 電話・手渡しで声をかけるときの言いかた（読み上げ用）

第1回は、チラシだけでは人が来ません。紙は「知ってもらう」ため、④の電話と手渡しは「来てもらう」ためのものです。
準備リストのC欄のとおり、まず20人に声をかけてください。

**刷る前に決めるところ**（色のついた2か所）— 事前連絡の締切（12月8日としています）と、記念品の中身。
印刷は**10月26日まで**に終えて役場へお持ちください。町広報の原稿締切はさらに早いので、先に確認を。

## 印刷するとき

ブラウザの印刷機能（Ctrl+P / ⌘+P）で、そのまま **A3・縦** で刷れます（用紙サイズはHTML側で指定済み）。

- 印刷設定で「背景のグラフィック」にチェックを入れてください（色分けが出ます）
- A4で刷りたいときは、印刷設定の用紙サイズをA4に変えて「用紙に合わせる」を選んでください
- 住民向けの案内文だけを配りたいときは、最後のページ（枠で囲んだ部分）を使ってください
- 準備リストと開催要項、チラシはA4縦です（こちらも「背景のグラフィック」にチェックを）
- チラシはA4縦1枚に収まるよう組んであります。文面を足すとはみ出しますので、足したぶんはどこかを削ってください

## 決裁の前に確認するところ

- **時期・数値・金額はすべてたたき台です。** 予算年度と職員体制に合わせて積み直してください
- 町の地域福祉計画・地域福祉活動計画のどの項目に紐づけるか
- 会場と曜日（毎回同じ場所・同じ曜日にできるところ）
- 住民向けページの「毎月 第◯◯曜日」「ところ」は、決まりしだい入れてください
- 参加費100円は提案です。無料にする場合は、その分の予算措置が必要です
