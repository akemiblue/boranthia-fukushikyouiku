# ボランティアカフェ

大郷町社会福祉協議会　ボランティアセンター事業の新規プログラム。

平時から住民どうしが顔見知りになる場をつくり、孤立・孤独のない地域をめざします。
講座（知る）と活動（やってみる）のあいだにある「また会う」場を、この事業で埋めます。

## ファイル

- `volunteer-cafe-roadmap.html` — 構想と行程（ロードマップ）第1版。ブラウザで開けます。1ファイル完結。

## 収録している内容

- ビジョン（住民に示すことば）と、共有したい3つの考え方
- 「つながりの環」の図 — いま欠けている環がどこかを示したもの
- 4年間のロードマップ（準備期／第1期 定着／第2期 展開／第3期 住民の手に）
  - 各期の「この期の問い」「やること」「到達のめやす」
- 当日90分の型（受付から、ふりかえりまで）
- 評価のしかた — 出会い・関係・動きの3層と、いちばん大事なひとつの数字
- 体制と役割、予算のめやす
- つまずきそうなところと、打ち手（6項目）
- これからの3か月でやること
- 住民向けの案内文（チラシ・回覧・町広報の原稿としてそのまま使えます）

## 印刷するとき

ブラウザの印刷機能（Ctrl+P / ⌘+P）で、そのまま **A3・縦** で刷れます（用紙サイズはHTML側で指定済み）。

- 印刷設定で「背景のグラフィック」にチェックを入れてください（色分けが出ます）
- A4で刷りたいときは、印刷設定の用紙サイズをA4に変えて「用紙に合わせる」を選んでください
- 住民向けの案内文だけを配りたいときは、最後のページ（枠で囲んだ部分）を使ってください

## 決裁の前に確認するところ

- **時期・数値・金額はすべてたたき台です。** 予算年度と職員体制に合わせて積み直してください
- 町の地域福祉計画・地域福祉活動計画のどの項目に紐づけるか
- 会場と曜日（毎回同じ場所・同じ曜日にできるところ）
- 住民向けページの「毎月 第◯◯曜日」「ところ」は、決まりしだい入れてください
- 参加費100円は提案です。無料にする場合は、その分の予算措置が必要です
